## Implementation Changes

   - Required because clone elements are different object instances than live elements

3. takePreHoverSnapshot replaces takeVisibilitySnapshot in handleMouseEnter baseline
4. detectVisibilityTransition takes fresh snapshot from live DOM for comparison
5. Container does NOT use visibility:hidden (would cascade false invisibility)

## Key Discovery
JS-driven menus are now detected by BOTH mechanisms:
- Clone: The baseline is taken BEFORE JS fires (at mouseenter). By dwell fire, JS has
  modified the DOM (display:none→block). Clone baseline captured the pre-JS state.
- MO: May also detect the mutations depending on scope (target vs parent).

The clone baseline is actually MORE reliable than MO for JS-driven menus because it
captures the pre-event state regardless of which element the JS modifies.
