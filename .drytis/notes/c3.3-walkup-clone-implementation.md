# C3.3 Incremental Walk-Up Clone — Implementation Record

## Date
2026-07-15

## Problem
The DOM Clone Baseline (previous approach) cloned only `target.parentElement` to an off-screen container. For Adani One's CSS mega-menu pattern, the hiding selector `.PrimaryMenu_mainNav > ul > li.PrimaryMenu_subMenuParent ul.PrimaryMenu_subMenu { display: none; }` requires the full ancestor chain. Cloning just the `<LI>` breaks the selector, making the submenu appear visible (display:block) in the clone — producing a false baseline with 0 invisible elements → no transition detected → Gate 5 fails.

## Solution: Incremental Walk-Up Clone
Walk UP from `target.parentElement`, cloning at each ancestor level. At each level:
1. Clone `currentAncestor` subtree to off-screen container
2. Read getComputedStyle on all descendants
3. Check if clone has invisible elements
4. If yes → this is the effective scope, stop
5. If no → walk up to parent, repeat

MAX_WALKUP_LEVELS = 4 (safety limit).

For Adani One: Level 0 (LI) has the hidden submenu as a direct child → finds invisible elements at level 0. effectiveScope = the LI.
