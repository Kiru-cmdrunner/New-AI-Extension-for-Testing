# C6.2A — Date Picker / Select Conflict Fix

## Problem
When clicking a date on Adani One's calendar, the selection is recorded as a
"Select" interaction instead of a "dateSelect" interaction.

## Root Cause Analysis
Three overlapping defects:

### D1: Calendar cell selector too narrow
`CALENDAR_GRIDCELL_SELECTOR = '[role="gridcell"], [data-date], td[aria-label]'`

This misses common calendar patterns:
- Flatpickr: `<span class="flatpickr-day">` (no role, no data-date)
- react-datepicker: `<div class="react-datepicker__day">`
- Custom: `<button>` or `<div>` with aria-label date inside calendar container
- Adani One likely uses `<button>` or `<div>` cells without `role="gridcell"`

### D2: select-content-script catches date cells
`handleGenericSelectionGroup` (CSS class differential) catches date cells
that receive `selected`/`active` class after click, recording them as Select.
`handleOptionClick` catches cells inside `[role="listbox"]` containers (some
calendar libraries use listbox for the date grid).

No skip for calendar containers exists in select-content-script.

### D3: resolveCalendarCell uses global `event` instead of parameter
`resolveCalendarCell(rawTarget)` at line 508 references the global `event`
variable instead of the event passed to `handleCalendarCellMousedown`.
This is fragile and may fail in certain browser contexts.

## Fix Strategy

### Fix D1: Broaden calendar cell detection
Expand `CALENDAR_GRIDCELL_SELECTOR` to also match:
- Any element with `aria-label` containing a date-like pattern inside a calendar container
- `[role="gridcell"]`, `[data-date]`, `[data-day]`, elements with date-like text inside calendar

Better approach: Use a two-pass strategy:
1. Match specific selectors first (fast path)
2. For cells inside calendar containers, check for date-like content (aria-label, text content)

### Fix D2: Add calendar skip in select-content-script
Add `DATEPICKER_CELL_SELECTOR` and `DATEPICKER_CONTAINER_SELECTOR` to
`handleGenericSelectionGroup` skip list, and add calendar container check
in `handleOptionClick` to skip `[role="option"]` inside calendar containers.

### Fix D3: Pass event through resolveCalendarCell
Change `resolveCalendarCell` to accept the event parameter instead of
using global `event`.
