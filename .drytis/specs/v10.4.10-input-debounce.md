# Spec: Input Debounce + Redundant Event Suppression

## v10.4.9 — Redundant Event Suppression

### Bug 1: Checkbox click produces 4 raw events (CLK label + CLK checkbox + INP + CHG)
Clicking a checkbox wrapped in a `<label>` fires click on label, click on input, input event, and change event.

**Fix**: 
- Suppress input/change on checkbox/radio (click handler captures checked state via deferred read)
- Suppress input on SELECT (change carries the committed value)
- Suppress click on `<label>` elements wrapping inputs (browser forwards label clicks to the input)

## v10.4.10 — Input Debounce

### Bug: Typing a mobile number captures every keystroke as a separate INP event
Typing "9897654321" produces 10 separate INP events ("" → "9", "9" → "98", etc.), flooding the timeline.

**Fix**: Debounce input events with an 800ms timer:
- First keystroke captures valueBefore from valueTracker (set on focus/mousedown)
- Subsequent keystrokes reset the timer
- After 800ms of no typing, ONE coalesced INP event is sent with full transition
- Flush points: blur (scoped to same element), pagehide, STOP_RECORDING

### Classifier grouping window extension
Extended from 500ms to 30s for text-entry elements (INPUT/TEXTAREA/textbox role) because debounced input fires 800ms after typing pauses, and blur fires whenever the user moves on — both well beyond the old 500ms window.

## Acceptance Criteria

- [ ] Typing a 10-digit number produces ONE INP event, not 10
- [ ] Checkbox click in label produces ONE Checkbox interaction
- [ ] Dropdown SELECT selection produces click + change (no INP)
- [ ] Regular text input produces focus + input + blur grouped as one TextEntry
- [ ] No input data lost on blur, page navigation, or recording stop
- [ ] All existing tests pass

## Constants

- `INPUT_DEBOUNCE_MS = 800` — typing pause threshold before coalesced event fires
- Text-entry grouping window: `30000` (30s) — covers real-world typing duration
- SELECT grouping window: `30000` (30s) — covers dropdown browsing time
- Non-text-entry grouping window: `500` (500ms) — original default

## Flush Points (data safety)

1. **Timer expiry** — 800ms after last keystroke
2. **blur** — scoped to same element (prevents field-switch race)
3. **pagehide** — page unload/navigation
4. **STOP_RECORDING** — recording stopped by user
