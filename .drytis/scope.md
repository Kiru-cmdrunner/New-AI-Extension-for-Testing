# AI Extension for CmdRunner — Scope

## Milestone 1 — Extension Foundation

### In Scope
- Manifest V3 Chrome Extension
- Modern Chrome Side Panel UI
- Recording states: Ready, Recording, Stopped
- Start Recording / Stop Recording buttons (UI state only — no actual recording)
- Settings page with placeholder sections: General, AI, Recording, About
- Storage Service to persist last UI state
- Modular project architecture

### Out of Scope (Milestone 1)
- Browser event recording
- AI integration
- Element identification
- JSON generation
- Plain English test steps
- CmdRunner integration

### Future Milestones
- M2: Smart Interaction Observer (event capture)
- M3: AI Enrichment (NL step generation, test case building)
- M4: CmdRunner Integration & Export
