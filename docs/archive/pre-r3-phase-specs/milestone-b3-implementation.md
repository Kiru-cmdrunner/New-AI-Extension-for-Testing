# Milestone B3 — Artifact Generation Engine Foundation

## Objective
Implement the foundation of the Artifact Generation Engine per frozen B2 architecture.

## Files to Create
1. `src/generation/contracts/generator-contract.ts` — Contract types
2. `src/generation/registry/generator-registry.ts` — Generator registry
3. `src/generation/generators/canonical-step-generator.ts` — First generator (pure function)
4. `src/generation/engine/generation-engine.ts` — Orchestrator
5. `src/generation/types.ts` — Generator-specific types (CanonicalStep, GeneratorResult)
6. `tests/generation-engine.test.ts` — Tests

## Files to Modify
1. `src/shared/types.ts` — Add TestCaseState.GENERATING, StorageKeys.GENERATED_STEPS, new message types
2. `src/storage/storage-service.ts` — Add getGeneratedSteps/setGeneratedSteps
3. `src/background/service-worker.ts` — Remove live step generation, invoke GenerationEngine on Stop
4. `src/recorder/recording-session.ts` — Remove step management (session captures events only)
5. `src/manifest.json` — Bump version to 4.1.0

## Acceptance Criteria
- [ ] Generator contracts defined (input, output, result)
- [ ] Generator registry registers and resolves execution order
- [ ] Canonical Step Generator is a pure function (no side effects)
- [ ] Generation Engine orchestrates pipeline on Stop Recording
- [ ] TC transitions: RECORDED → GENERATING → GENERATED
- [ ] Live step generation removed from processAction()
- [ ] Navigation steps generated by Canonical Step Generator, not webNavigation handler
- [ ] No steps exist during recording
- [ ] Steps generated only after Stop
- [ ] B4 (JSON Gen) and B5 (Playwright Gen) can be added without modifying the engine
- [ ] All existing tests pass
- [ ] New tests pass
